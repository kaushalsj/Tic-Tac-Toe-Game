# Tic Tac Toe Using Minimax Algorithm

## Description

This project is a Tic Tac Toe game developed in Python using the Minimax Algorithm. The AI opponent makes optimal moves, making the game challenging for the player.

## Features

* Human vs AI gameplay
* Minimax algorithm for optimal decision-making
* Win, Loss, and Draw detection
* Command-line interface (CLI)
* Game result tracking

## Technologies Used

* Python
* Minimax Algorithm

## How to Run

1. Install Python.
2. Run the Python file:
   python tic_tac_toe.py
3. Follow the on-screen instructions to play.
